# Модули материалов террейна

Основной шейдер `../voxel_surface.gdshader` остаётся единым шейдером для поверхности чанков. Он отвечает за выбор материала по vertex color, LOD, обработку граней, освещение и тени.

Материальные функции вынесены в подключаемые файлы `.gdshaderinc`:

- `common.gdshaderinc` — общие uniforms, varying и базовые функции цвета/шума.
- `grass.gdshaderinc` — палитра и окраска травы для ближних и дальних LOD.
- `soil.gdshaderinc` — палитра и окраска почвы.
- `sand.gdshaderinc` — окраска песка; сохранён прежний цвет и один шумовой sample.
- `underwater.gdshaderinc` — окраска подводных водорослей.
- `mountain.gdshaderinc` — параметры, палитра и рисунок горной породы.

## Важные правила

1. Не добавляйте сюда отдельные `shader_type` или `render_mode`: они принадлежат главному шейдеру.
2. Общие uniforms и varying объявляются только в `common.gdshaderinc` либо в главном шейдере. Не дублируйте их в материальных модулях.
3. Выбор типа поверхности по vertex color и alpha-кодам остаётся в `fragment()`. Эти коды согласованы с native VoxEn builder.
4. LOD, освещение, тени и обработку геометрии меняйте отдельно от цветовых функций материалов.
5. Для изменения внешнего вида материала сначала редактируйте соответствующий модуль. Подключение новых текстур и PBR-карт можно добавить позднее, не меняя маршрутизацию материалов.

Модули подключаются через `#include` в начале `voxel_surface.gdshader`. Это структурное разделение исходного кода, а не создание отдельных ShaderMaterial для каждого типа поверхности.
