# ADR-014. CI с автоматической сборкой DLL

- **Статус:** Принцип ROADMAP
- **Источник:** ROADMAP.md, раздел 25

## Решение / направление

GitHub Actions на Windows runner собирает GDExtension для Windows x86-64 и запускает smoke-тесты на push и pull request. CI не заменяет локальную визуальную проверку и performance benchmark.

## Ограничение 0.1.0.4

Этот релиз посвящён структурной реорганизации существующей реализации. ADR не разрешает менять алгоритмы генерации или вводить будущие системы раньше соответствующего этапа ROADMAP.
