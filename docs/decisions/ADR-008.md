# ADR-008. Отделить TerrainField от мешера

- **Статус:** Направление принято, внедрение по этапам
- **Источник:** ROADMAP.md, раздел 25

## Решение / направление

Потребители данных работают через единый интерфейс TerrainField. Мешер получает выборки поля и параметры построения, но не определяет правила генерации. HeightfieldTerrainFieldAdapter сохраняет текущую модель на переходном этапе.

## Ограничение 0.1.0.4

Этот релиз посвящён структурной реорганизации существующей реализации. ADR не разрешает менять алгоритмы генерации или вводить будущие системы раньше соответствующего этапа ROADMAP.
