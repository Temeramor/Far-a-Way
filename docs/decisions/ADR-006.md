# ADR-006. Стратегия хранения объёмных данных: procedural + delta

- **Статус:** Требуется исследование или отдельное решение
- **Источник:** ROADMAP.md, раздел 25

## Решение / направление

Для неизменяемых зон предполагается procedural sampling; пользовательские изменения хранятся в sparse delta patches. Гипотеза требует измерений памяти, скорости выборки, сохранения и загрузки.

## Ограничение 0.1.0.4

Этот релиз посвящён структурной реорганизации существующей реализации. ADR не разрешает менять алгоритмы генерации или вводить будущие системы раньше соответствующего этапа ROADMAP.
