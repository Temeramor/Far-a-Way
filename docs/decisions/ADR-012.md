# ADR-012. Встроить визуальную оценку в тестовый процесс

- **Статус:** Принцип ROADMAP
- **Источник:** ROADMAP.md, раздел 25

## Решение / направление

Для контрольных seed сохраняются эталонные скриншоты и диагностические карты. Проверяются берег, горы, долины, сток, подводный рельеф и сохранение крупных форм при смене LOD.

## Ограничение 0.1.0.4

Этот релиз посвящён структурной реорганизации существующей реализации. ADR не разрешает менять алгоритмы генерации или вводить будущие системы раньше соответствующего этапа ROADMAP.
