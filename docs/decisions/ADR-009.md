# ADR-009. Не менять сразу весь VoxelWorld

- **Статус:** Принцип ROADMAP
- **Источник:** ROADMAP.md, раздел 25

## Решение / направление

VoxelWorld разделяется на независимые обязанности без изменения результата. Изменение геометрии не должно затрагивать streaming priorities, cache и diagnostics; новые интерфейсы не должны требовать прямого доступа к внутренним Dictionary координатора.

## Ограничение 0.1.0.4

Этот релиз посвящён структурной реорганизации существующей реализации. ADR не разрешает менять алгоритмы генерации или вводить будущие системы раньше соответствующего этапа ROADMAP.
