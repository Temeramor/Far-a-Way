# ADR-002. Перейти к Terrain Generation Pipeline

- **Статус:** Направление принято, внедрение по этапам
- **Источник:** ROADMAP.md, раздел 25

## Решение / направление

Генерация оформляется как последовательность независимых passes с явными входами, выходами, параметрами и зависимостями. Pass не создаёт Node, ArrayMesh или физические ресурсы; старый макрогенератор подключается как один из этапов.

## Ограничение 0.1.0.4

Этот релиз посвящён структурной реорганизации существующей реализации. ADR не разрешает менять алгоритмы генерации или вводить будущие системы раньше соответствующего этапа ROADMAP.
