# ADR-005. Использовать Hybrid Heightfield + SDF

- **Статус:** Принцип ROADMAP
- **Источник:** ROADMAP.md, раздел 25

## Решение / направление

Heightfield остаётся источником базовой формы, SDF предназначен для сложной объёмной геометрии. Coast SDF в X/Z не является трёхмерным SDF. Переход выполняется только после отдельного прототипа.

## Ограничение 0.1.0.4

Этот релиз посвящён структурной реорганизации существующей реализации. ADR не разрешает менять алгоритмы генерации или вводить будущие системы раньше соответствующего этапа ROADMAP.
