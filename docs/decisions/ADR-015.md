# ADR-015. Единственный авторитетный источник горного профиля — C++

- **Статус:** Принцип ROADMAP
- **Источник:** ROADMAP.md, раздел 25

## Решение / направление

Авторитетный источник горных массивов — Massif в C++ PgIslandTerrain. GDScript-сегменты объявляются устаревающими и удаляются только после parity-проверки и обновления тестов.

## Ограничение 0.1.0.4

Этот релиз посвящён структурной реорганизации существующей реализации. ADR не разрешает менять алгоритмы генерации или вводить будущие системы раньше соответствующего этапа ROADMAP.
