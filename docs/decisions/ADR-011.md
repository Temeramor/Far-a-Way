# ADR-011. Оставить генерацию и runtime streaming разными системами

- **Статус:** Принцип ROADMAP
- **Источник:** ROADMAP.md, раздел 25

## Решение / направление

Generation Pipeline отвечает за данные; runtime streamer решает, какие чанки нужны, в каком LOD и с каким приоритетом. Связь — через явные контракты.

## Ограничение 0.1.0.4

Этот релиз посвящён структурной реорганизации существующей реализации. ADR не разрешает менять алгоритмы генерации или вводить будущие системы раньше соответствующего этапа ROADMAP.
