# ADR-004. Geological profile как набор весов

- **Статус:** Направление принято, внедрение по этапам
- **Источник:** ROADMAP.md, раздел 25

## Решение / направление

Не использовать enum геологических типов. Профиль задаётся числовыми весами для смешанных типов; пресеты являются сохранёнными наборами весов. Новая геология не внедряется в чистом рефакторинге.

## Ограничение 0.1.0.4

Этот релиз посвящён структурной реорганизации существующей реализации. ADR не разрешает менять алгоритмы генерации или вводить будущие системы раньше соответствующего этапа ROADMAP.
