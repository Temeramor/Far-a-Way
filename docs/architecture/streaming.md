# Streaming scripts

Точки входа и карта слоёв перечислены в [обзоре архитектуры](README.md). Исходные пути сохранены, чтобы не менять ссылки сцен и preload. State-файлы содержат общие поля; слои наследования организованы по зависимостям локальных методов.

Это структурное разделение исходников, а не утверждение о завершённом выделении всех независимых runtime-сервисов. Контракты StreamingPlanner, MeshJobScheduler, MeshDataCache и ChunkResourceManager остаются целями этапа 1 ROADMAP; дальнейшее выделение должно сопровождаться тестами и parity-проверками.
