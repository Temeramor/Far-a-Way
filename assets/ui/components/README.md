# Neverland modular button layers

These transparent PNG layers are generated by `tools/generate_ui_assets.py`.
They are deliberately separate so the button face, ornate frame and moss can be
re-coloured, replaced or layered independently in other UI scenes.

## Base layers

- `button_surface_primary.png` — warm aged-wood face for primary actions.
- `button_surface_secondary.png` — dark teal face for secondary actions.
- `button_frame.png` — gold stepped border with matching side diamonds and corner scrollwork.
- `moss_strip.png` — softly irregular green moss with pixel flecks and hanging shoots.

Matching `_hover` and `_pressed` variants are supplied for interactive states, as
well as `button_frame_secondary.png` and `moss_strip_secondary.png` for the teal
style. Use nearest-neighbour filtering to preserve the pixel edges.

The generator also composites the independent layers into `button_primary.png`,
`button_secondary.png`, `button_hover.png`, and `button_pressed.png`. These are the
textures currently consumed by the main menu's nine-patch button styles, which
keeps the ornaments crisp when buttons are resized.

To regenerate the layers and preview, install Pillow and run from the project root:

```bash
python tools/generate_ui_assets.py
```
