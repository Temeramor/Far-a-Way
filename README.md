# Far a Way

**Версия:** 0.1.0.1  
**Статус:** ранний технический прототип  
**Платформа:** Windows x86-64  
**Движок:** Godot 4.7.2 · **Рендерер:** Forward+

Far a Way — проект будущей стратегии в реальном времени (RTS) с элементами выживания. Задумка игры — большой процедурно создаваемый мир, в котором развитие, управление и взаимодействие с окружением будут иметь не меньшее значение, чем само исследование локации.

Сейчас проект находится на ранней технической стадии. Текущая сборка посвящена прежде всего генерации мира, отображению больших расстояний, потоковой загрузке ландшафта и базовому перемещению по нему. Это уже запускаемый игровой прототип, но ещё не готовая RTS.

## Направление игры

В дальнейшем Far a Way должна объединить стратегическое управление и элементы выживания: игрок будет развивать своё присутствие в мире, распоряжаться доступными возможностями и учитывать условия окружающей среды. Процедурная генерация локаций и работа с большими пространствами закладываются как основа для этих систем.

Стратегическое управление, строительство, производство, сбор ресурсов, боевые подразделения и полноценные механики выживания пока находятся за пределами текущей сборки.

## Что доступно сейчас

### Процедурный мир

- Локация размером **2 × 2 км**, создаваемая на основе заданного seed.
- Повторный запуск с тем же seed воспроизводит тот же рельеф.
- Генерация холмов, горных цепей, склонов и переходов между травяными и каменистыми поверхностями.
- Процедурная окраска поверхности: травяная палитра, каменные оттенки, минеральные слои, трещины и мелкие детали скальной породы.
- Базовый размер ячейки террейна — **0,2 м** по всем трём осям.

Ландшафт сейчас построен как модель высотных колонн: для каждой горизонтальной позиции рассчитывается высота поверхности. Это позволяет эффективно создавать большие открытые пространства, но не образует полноценный редактируемый трёхмерный воксельный объём.

### Потоковая загрузка и LOD

Мир разделён на чанки, которые создаются по мере необходимости вокруг игрока. Для разных расстояний используются восемь уровней детализации:

| Уровень | Размер ячейки |
|---|---:|
| LOD 0 | 0,2 м |
| LOD 1 | 0,4 м |
| LOD 2 | 0,8 м |
| LOD 3 | 1,6 м |
| LOD 4 | 3,2 м |
| LOD 5 | 6,4 м |
| LOD 6 | 12,8 м |
| LOD 7 | 25,6 м |

Система потоковой загрузки учитывает положение и направление движения игрока, поддерживает соседние уровни детализации и использует родительские чанки как временное покрытие, пока необходимые дочерние чанки ещё готовятся. Базовый размер чанка — 32 м, стандартная дальность отображения — 4 096 м.

Генерация мешей террейна выполняется через нативное расширение C++ GDExtension. Для фоновой работы используются задачи Godot `WorkerThreadPool`; GDScript-вариант построителя террейна остаётся резервным путём.

### Растительность и камни

На поверхности процедурно размещаются:

- пучки травы с несколькими вариантами формы и оттенка;
- цветы разных форм и цветовых сочетаний;
- отдельные камни и валуны, чаще встречающиеся на каменистых участках.

Геометрия декора объединяется в меши по тайлам. Её расчёт выполняется в фоновых задачах, а создание игровых узлов, мешей и коллизий — в главном потоке. Для растений предусмотрены два уровня детализации; движение травы и цветов зависит от выбранной погоды.

### Небо, освещение и погода

В игре уже работает система окружающей среды:

- движение Солнца и Луны;
- смена времени суток и звёздное небо;
- облака и атмосферный туман;
- направленное освещение и тени рельефа;
- три погодных пресета: **Ясно**, **Облачно**, **Пасмурно**;
- четыре пресета времени: **Рассвет**, **День**, **Закат**, **Ночь**.

### Перемещение по миру

Сейчас доступен базовый контроллер от первого лица:

- ходьба по поверхности с гравитацией;
- обзор мышью;
- свободный полёт по направлению камеры;
- переключение между ходьбой и полётом двойным нажатием пробела.

Этот режим предназначен для исследования локации и проверки генерации, а не является финальной системой управления RTS.

### Меню и настройки

- Главное меню с запуском новой игры, настройками и выходом.
- Ввод seed числом или произвольным текстом.
- Экран загрузки с отображением прогресса подготовки мира.
- Настройки скорости полёта и угла обзора камеры.
- Меню паузы с продолжением игры, настройками экрана и возвратом в главное меню.
- Выбор оконного или полноэкранного режима и разрешения от 640 × 360 до 2560 × 1440.
- Сохранение пользовательских настроек между запусками.

### Диагностика производительности

Во время игры клавиша **F3** открывает панель VoxEn Diagnostics. Она показывает FPS и время кадра, распределение чанков по LOD, количество вершин и индексов, оценку памяти мешей, видеопамять, количество коллизий, состояние очередей задач и статистику времени генерации.

## Управление

| Клавиша | Действие |
|---|---|
| **W / A / S / D** или стрелки | Перемещение |
| **Мышь** | Обзор |
| **Пробел × 2** | Включить или выключить полёт |
| **M** | Открыть или закрыть меню погоды и времени |
| **Esc** | Открыть паузу или вернуться из неё |
| **F3** | Показать или скрыть диагностику VoxEn |

## Текущие ограничения

Текущая версия — исследовательская основа будущей игры. В ней пока нет стратегического игрового цикла и связанных с ним систем: управления отрядами, строительства, производства, сбора ресурсов, сражений, инвентаря, крафта, голода или жажды.

Текущая модель рельефа также не поддерживает пещеры, нависающие участки, произвольное разрушение и редактирование вокселей. Для таких возможностей потребуется переход от модели высотных колонн к более полноценному представлению объёма.

## Запуск проекта

1. Установите **Godot 4.7.2**.
2. Откройте в редакторе Godot файл `project.godot`.
3. Используйте рендерер **Forward+**.
4. Запустите проект из редактора или соберите Windows-версию.

В репозитории находится исходный код нативного расширения и файл его описания `bin/voxen_native.gdextension`. Готовые DLL в репозиторий не включены. Для штатной производительности рекомендуется собрать расширение под Windows x86-64. При отсутствии библиотеки проект использует резервный GDScript-построитель террейна, который работает медленнее.

## Сборка нативного расширения Windows

Необходимы Windows x86-64, Visual Studio C++ Build Tools, Python, SCons и Godot C++ bindings для Godot 4.7.2.

Из корня проекта:

```powershell
git clone --depth 1 --branch 10.0.0-stable https://github.com/godotengine/godot-cpp.git native/godot-cpp
python -m pip install --upgrade scons

cd native
scons platform=windows target=template_debug arch=x86_64
scons platform=windows target=template_release arch=x86_64
```

Собранные библиотеки размещаются в `bin/windows/`:

- `voxen_native.windows.template_debug.x86_64.dll`
- `voxen_native.windows.template_release.x86_64.dll`

## Проверка проекта

При установленном Godot 4.7.2 тесты можно запустить из корня проекта:

```powershell
godot --headless --editor --path . --quit
godot --headless --path . --script res://tests/terrain_smoke_test.gd
godot --headless --path . --script res://tests/lod_hierarchy_smoke_test.gd
godot --headless --path . --script res://tests/shadow_lod_smoke_test.gd
godot --headless --path . --script res://tests/voxel_surface_scatter_smoke_test.gd
```

## Структура проекта

- `scenes/` — главное меню, игровой мир, игрок и экран загрузки.
- `scripts/menu/` — главное меню и запуск новой игры.
- `scripts/player/` — контроллер игрока.
- `scripts/world/` — генерация мира, погода и размещение декора.
- `scripts/vegetation/` — сетки, палитры и сборка мешей растительности и камней.
- `scripts/voxel_world.gd`, `scripts/voxel_chunk.gd` — стриминг чанков, LOD и ресурсы мира.
- `native/src/` — C++-построитель террейна и регистрация GDExtension.
- `shaders/` — материалы поверхности, растительности и неба.
- `tests/` — smoke-тесты генератора, LOD, теней и декора.
